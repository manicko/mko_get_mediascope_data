У нас есть настройки отчетов по умолчанию:

C:\py_exp\mko_get_mediascope_data\src\mko_get_mediascope_data\settings\defaults\tv

Но в них описаны не все параметры.

Нам нужно в этой папке создать дополнительный файл с описанием параметров отчетов, систематизировав их по типам отчетов.
Причем, нужно, чтобы при инициализации этот файл тоже выгружался пользователю. Формат лучше md, если это сложно реализовать, то можно .json5

Описание делаем на английском. 


Параметры берем отсюда:

https://docs.mediascope.net/xwiki/bin/view/Main/TV%20Index%20API/TVI%20API%3A%20статистики/

https://docs.mediascope.net/xwiki/bin/view/Main/TV%20Index%20API/TVI%20API%3A%20фильтры%20и%20срезы/Отчет%20Timeband/

https://github.com/MEDIASCOPE-JSC/mediascope-jupyter/blob/main/tv_index/_help.ipynb


Нужно именно корректно все систематизировать, у поставщика сейчас отратительно сделано. 

Поэтому, в спецификации поставь задачу на нескольких reseаrcher агентов.

1. 2 агента - собрать информацию с сайта поставщика (одинаковое задание, агенты ошибаются, надо дублировать)
2. собрать информацию из наших шаблонов и сгруппировать
3. Самый важный агент - систематизировать информацию из разных отчетов на основе мировых практик систематизации и создать документ. Лучше это поручить auditor
4. Validator для проверки
5. Исправление по результату.
